# AR Image Tracking — HUAWEI AR Engine

Отдельное приложение: распознавание картинки-метки (Image Tracking) и показ 3D-модели поверх неё.

## Как пользоваться
1. Запустить приложение на Huawei (нужен сервис HUAWEI AR Engine — приложение предложит установить).
2. Открыть `assets/marker.png` (или `marker.png` из архива) на мониторе / распечатать / нажать «Показать метку» на другом телефоне.
3. Навести камеру на картинку — над ней появится ракета (`assets/rocket.obj`). Потеряли картинку — модель исчезает.
4. Взаимодействие: тап по модели — подпрыгивает и меняет цвет; один палец — поворот; два пальца — масштаб.

## Пункты задания
| Требование | Реализация |
|---|---|
| Метка с учётом ограничений | `marker.png` 1024×1024: контрастная, без повторяющегося узора и симметрии, много уникальных деталей |
| Компоненты Image Tracker | `ARImageTrackingConfig` + `ARAugmentedImageDatabase.addImage(...)` (MainActivity) |
| 3D-модель | `rocket.obj` + `rocket.mtl`, свой загрузчик OBJ (`ObjModel.kt`) |
| Появление модели привязано к распознаванию | модель рисуется только пока `ARAugmentedImage` в состоянии `TRACKING` (ImageRenderer) |
| Взаимодействие касанием | луч из точки касания против сферы модели; тап/поворот/масштаб (ImageRenderer.handleTouch) |

## Сборка
Android Studio → открыть папку → Gradle JDK 17 → Sync → Run.
